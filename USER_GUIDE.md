# Daily Routine App - User Guide

## Getting Started

### First Launch
When you first open the app, you'll see an empty "Today" view with a floating action button (+) in the bottom right corner.

## Creating Your First Routine

1. **Tap the + button** in the bottom right corner
2. **Enter a routine name** (e.g., "Morning Routine", "Workout", "Evening Checklist")
3. **Tap "Create"**
4. You'll be taken to the routine detail screen

## Adding Items to a Routine

1. **From the routine detail screen**, tap the + button
2. **Enter the item description** (e.g., "Brush teeth", "Make bed", "Drink water")
3. **Tap "Add"**
4. Repeat to add more items

Items appear in the order you add them.

## Using the Today View

The main screen shows all your active routines for today:

### Checking Off Items
- **Tap the circle icon** next to any item to mark it complete
- Completed items show a checkmark ✓
- Incomplete items show an empty circle ○

### Viewing Progress
Each routine card shows:
- Routine name
- All items in order
- Completion count (e.g., "3 of 5 completed")

### Opening Routine Details
- **Tap anywhere on a routine card** to open the detail view
- From here you can add/remove items

## Managing Items

### Deleting Items
1. Open the routine detail screen
2. Tap the **trash icon** next to an item
3. The item will be removed immediately

## Daily Reset

**Items automatically reset each day!**
- Your checklist starts fresh every morning
- Yesterday's completions are saved
- Today shows uncompleted items

## Free vs Premium

### Free Tier (Default)
- Create up to **3 routines**
- Unlimited items per routine
- Full app functionality

### Premium (In-App Purchase)
- **Unlimited routines**
- Support development
- No other restrictions

### Upgrading to Premium
Currently, premium upgrades are handled through Google Play Billing. 
(Note: In this MVP, the billing integration is set up but would require Play Store configuration)

## Tips & Best Practices

### Organizing Routines
- Keep routines focused (morning, evening, workout, etc.)
- Use clear, actionable item descriptions
- Order items logically (start to finish)

### Optimal Item Count
- 3-7 items per routine is most manageable
- Break large routines into multiple smaller ones

### Daily Habits
- Check the app first thing in the morning
- Mark items complete as you go
- Review at end of day for satisfaction

## Privacy & Data

### Local Storage
- All data stored on your device
- No cloud sync
- No account required
- No tracking

### Data Persistence
- Data persists between app sessions
- Survives app updates
- Can be cleared via Android settings

### Backup
Since there's no cloud sync:
- Use Android backup if available
- Or manually note routines elsewhere
- Future versions may add export/import

## Troubleshooting

### Items Not Appearing
- Make sure you're viewing the correct routine
- Check if you tapped "Add" after entering text

### Can't Create More Routines
- Free tier limited to 3 routines
- Delete old routines to make space
- Or upgrade to Premium

### Items Not Staying Checked
- Completion state is per-day
- Items reset each new day
- This is by design for daily routines

### App Crashes
- Try restarting the app
- Clear app cache (Android Settings)
- Reinstall if issues persist

## FAQ

**Q: Can I rearrange items?**  
A: Not in current MVP. Items stay in creation order.

**Q: Can I edit item descriptions?**  
A: Not in current MVP. Delete and recreate if needed.

**Q: Can I share routines?**  
A: Not in current MVP. No sharing features yet.

**Q: Why do items reset daily?**  
A: The app is designed for daily routines that repeat each day.

**Q: Can I see history?**  
A: Not in current MVP. Focus is on today's tasks.

**Q: Does this work offline?**
